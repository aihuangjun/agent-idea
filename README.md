# Agent IDEA

Agent 开发配套的 IDEA：一个很轻的 macOS 工作台，用来看 Agent 的工作区（workspace）、看 Agent 改了什么，顺手改几笔、提交。

- **打开项目**：选一个目录（或把目录拖进窗口、`open -a AgentIDEA <目录>`），可同时开多个项目，顶栏切换；重启后自动恢复上次开着的项目。
- **目录树**：IDEA 习惯（单击选中、双击打开 / 展开），按 git 状态着色（修改蓝、新增绿、删除灰、忽略灰）；⌘ / ⇧ 点击多选，多选可一起拖走、一起删；右键「重命名…」或选中后按 ⇧F6 重命名，拖到另一个目录上移动（都同 IDEA：已跟踪的走 `git mv`，开着的标签跟着换）；右键「删除…」或选中后按 ⌫ 删文件 / 目录（进废纸篓，删前确认）；右键「新建文件夹…」；右键**「添加到 git」**把新建的（未跟踪）或被 `.gitignore` 忽略的东西纳入版本管理（IDEA 的 Add to VCS，只动索引不碰磁盘文件，⌘Z 可撤销；被忽略的会先确认再 `git add --force`）；「定位当前文件」（⌥⌘L）；右键 `.sh` / `.zsh` / `.fish` 脚本「在终端中运行」。
- **编辑**：代码与 Markdown 源码在 CodeMirror 编辑器里改，按语言高亮、括号匹配、自动缩进（Java、C / C++、Python、Go、TypeScript / TSX、JavaScript / JSX、JSON 用 tree-sitter 按语法树着色，见下方「阅读」）；行号右侧有相对 HEAD 的变更标记（改过的行蓝条、新增的行绿条，边敲边更新）。⌘S 保存；照 IDEA 的做法自动保存：关标签、切到别的应用、退出时都会写回磁盘，改过没保存的标签有个蓝点。保存保留原文件的编码与行尾。超过 2MB 的文件只读。别人在磁盘上改了你正在改的文件会在标题条提示。
- **阅读**：Markdown 预览 / 源码 / 分栏（左编辑右预览）三种看法，支持 mermaid、任务列表、相对图片；压成一行的 JSON 自动格式化显示；图片预览；自动换行、缩放。
- **语法着色**（照 IDEA）：Java、C / C++（.c / .h 也按 C++ 语法解析）、Python、Go、TypeScript（含 .tsx）、JavaScript（含 .jsx）、JSON 用 tree-sitter 解析，配色照 IntelliJ 新 UI 的 Dark / Light：函数声明与调用分开着色，参数（声明处与函数体里的每次引用）、局部变量、字段 / 属性（紫色）、全局变量与静态字段及常量（紫色斜体）、类型、类型参数、注解 / 装饰器、内建函数、Python 的 `self`、标签、文档注释、字符串里的转义都有各自的颜色。代码编辑器、全文 diff 的两侧、只读代码视图都适用，边改边增量更新。每种语言第一次打开时加载语法包（一眨眼），之前先显示普通高亮；超过 600KB 的文件、其他语言、diff 的补丁片段与 Markdown 里的代码块仍是普通的按词高亮。
- **后退 / 前进**（⌥← / ⌥→，标题条左侧也有按钮）：按打开顺序在标签间来回。
- **上一处 / 下一处变更**（⇧F7 / F7，标题条右侧也有上下箭头）：在 diff 或有改动的文件里逐处跳，跳到的那一行滚到正中。
- **diff 阅读设置**：默认折叠未修改区域，上下各保留 10 行上下文，可选 5 / 10 / 30 行；点击一次全部展开该区域，并保留原有代码在屏幕上的位置；编辑后不会重新折叠已展开内容。切换标签、并排 / 单列和主题时保留阅读现场。支持不忽略空白、忽略行尾空白、忽略空格与 Tab，过滤只改变比较结果，原文不变。工具栏显示“文件 n/m · 变更 n/m”；工作区和历史版本、并排和单列均支持。二进制或无法获取全文的大文件保留补丁视图。
- **diff 自动定位**：首次打开时跳到第一处差异，切回已访问的标签时恢复原位置；并排、单列和提交历史 diff 均支持。
- **Git**：显示当前分支；变更列表像 IDEA 提交窗口那样列出所有改动，点一条看 diff。**工作区变更的 diff 可以直接编辑**：并排视图左边是 HEAD 只读、右边是工作区文件（左侧行号旁的箭头可逐块回退，支持撤销），单列视图就是文件本身的编辑器（新增行带底色、被删的行以只读小块嵌在原位）。勾选要提交的文件，填信息，「提交」或「提交并推送」；右键可回滚、删除。**修改上一次提交**（Amend）：勾上之后上一次的提交信息自动填进输入框（取消勾选还原你原来写的），勾了文件就把它们并进上一次提交，什么都没勾就只改提交信息（终端里 `git add` 过的别的东西不会被带进去）；上一次提交已经推送过的话勾选旁边会警告「修改后需要强制推送」，此时「修改并推送」不可用——强制推送不替你做。**与远程同步**（⌘T，项目工具窗口标题条上的斜向下箭头，同 IDEA 的 Update Project）：`git fetch` 之后把上游的新提交 rebase 到本地分支下面，本地未提交的改动靠 `--autostash` 收起再放回。
- **显示历史**（目录树、标签右键，IDEA 的 Show History）：提交历史里只列动过这个文件的提交，文件改过名的话改名之前的也跟着找（`git log --follow`）；目录则列动过它下面任何文件的提交。顶上一条写着「a/b.swift 的历史」，✕ 退出回全部提交；选中某个提交时它排在文件列表最前、左边有一道强调色。与「区间比较」的比较模式互斥。
- **提交历史**（⌘9）：当前分支的提交列表（可翻页，新的在上），选中看它改了哪些文件、每个文件的 diff（只读）；右键某个文件「回滚这个变更…」，把那次提交对它的改动反向打回工作区，不产生提交。列表显示的是**提交时间**（提交落到本仓库的那一刻，也是排序依据）；rebase / cherry-pick / squash 过的提交作者时间与它对不上，详情里另注「编写于 …」。标题条的按钮在当前分支有上游时就是「与远程同步并刷新」（图标同项目工具窗口那个同步按钮），没有上游时只重列本地提交。
- **区间比较**（看 Agent 这一轮连着提交的几次总共改了什么）：提交历史里 ⇧点击连选、⌘点击增减，选中多于一个时详情显示「N 个提交 · M 个文件」和合并后的文件列表（最老那个的父提交 → 最新那个，根提交对空树），点文件看两侧全文的只读 diff，阅读设置、折叠、F7 与「文件 n/m」照常；右键某个提交「比较从这里到 HEAD」一步选好。分支弹窗里右键某个分支「与当前分支比较」，提交历史进入比较模式：顶上写着「与 origin/master 比较 · 3 个提交 · 12 个文件」，列表只列当前分支比它多的提交（`merge-base..HEAD`），什么都不选时看整段，✕ 退出回普通历史。区间 diff 的标签带「老…新」/「对比 分支」小标，与单个提交的区分开。
- **撤销 / 重做**（⌘Z / ⇧⌘Z）：焦点在编辑器里撤编辑，否则撤最近一次文件操作——重命名、移动、删除、回滚、新建文件夹、添加到 git，菜单项写着要撤的是哪一步。**编辑的撤销历史按文件存下来**：关掉标签、关项目、退出重启之后重新打开同一个文件，⌘Z 照样能撤回之前的修改；文件改名 / 移动后历史跟着走，删除后撤销删除也带回来。文件在关着的时候被 Agent 或别的程序改过，这份历史就作废（装回去会撕坏正文），从头记。
- **HTML**：`.html` / `.htm` 支持预览和可编辑源码切换；预览支持页面脚本、项目内 CSS、图片等相对资源，源码草稿也能直接预览。本地资源限于当前项目目录，预览页不持有编辑桥或全盘读取权限。
- **文件内查找**（⌘F / Ctrl+F）：代码、Markdown、HTML 和 diff 均可查找，支持区分大小写、上下查找与循环跳转；编辑器查全文，并排 diff 两侧都能查。
- **最近的文件**（⌘E，同 IDEA 的 Recent Files）：列出这个项目最近打开过的文件（关掉的也在，最多 50 个，重启后还在），当前文件不列，第一项就是上一个文件——⌘E 回车就切回去。输入即过滤（打分同查找文件），↑ ↓ 选、回车打开、Esc 关；磁盘上已经不在的自动剔掉，改名 / 移动后跟着换路径。
- **查找文件**（⇧⌘F）：按文件名 / 路径模糊搜索（支持子序列，`amdl` 能找到 `AppModel.swift`），回车打开并在树上定位。直接粘 Agent 输出里的引用也行：`Sources/Foo.swift:123`、`Sources/Foo.swift:123:5`、`./Sources/Foo.swift:12`、`Foo.swift#L12`、项目内的绝对路径都认，搜索框旁会标出认到的行号，回车打开后跳到那一行。
- **在项目中查找**（⌃⇧F，同 IDEA 的 Find in Path；「查找」工具窗口 ⌘3）：查「这个函数还有谁在调」「这个配置项哪里用到了」。编辑器里选中一段单行文字再按会自动填上。git 仓库里用 `git grep`，Agent 新建、还没 add 的文件也能搜到，被 `.gitignore` 忽略的和二进制文件不搜；不在 git 仓库里就逐个读项目里的文件（跳过二进制和超过 2MB 的）。可选区分大小写（Cc）、全词（W）、正则（.*，PCRE 语法，写错了直接说哪里不对）和文件掩码（`*.swift, !*Tests.swift`，不带 `/` 按文件名，带 `/` 按路径）。停手 300ms 就搜，结果按文件分组、可折叠，命中部分高亮，最多显示 1000 处。单击用预览标签打开并跳到那一行、把命中的文字选上，双击固定标签；↑ ↓ 换一处、回车打开；右键「复制引用」得到 `路径:行号`。搜的是磁盘上的内容，没保存的改动不算；Agent 又改了文件之后点标题条的刷新重搜。
- **跳到行**（⌘L，同 IDEA 的 Go to Line）：输入 `行` 或 `行:列`，回车跳过去并把那一行滚到正中，超出范围停在首 / 末行。代码编辑器、只读代码视图、diff（新版本那一侧）都能用；Markdown / HTML 正在预览时先切到源码（Markdown 切分栏）。
- **复制引用**（⌥⇧⌘C，同 IDEA 的 Copy Reference）：复制成相对项目根的 `路径:行号`，跨行选区是 `路径:12-20`，方便粘回给 Agent。编辑器、只读代码视图、diff（行号取新版本）里都能用；目录树和标签的右键菜单也有「复制引用」（目录树里只有路径）。没有行号的视图（Markdown 预览、图片）只复制路径。
- **回滚文件**：diff 正文、diff 标签和变更列表的右键菜单提供「回滚（Revert）」；用 ⌘ / ⇧ 点击多选后可批量回滚。点击直接执行，不弹确认，工作区回滚仍可用 ⌘Z 撤销。
- **自动刷新**：项目目录一有变化（Agent 在改），树、git 状态、正在看的文件自动更新；改过没保存的文件不会被覆盖。

界面照 IntelliJ 新版 UI，深浅两套主题（状态栏右下角切换，也在「视图 → 外观」里：跟随系统 / 浅色 / 深色，默认深色）。顶栏的项目标签能拖着换顺序，空白处双击 = 打开项目。

Diff 后续迭代顺序与完成状态见 [优化路线](ROADMAP.md)。

### 本地状态

全部在 `~/.agentidea/`：`recent.json`（最近项目）、`logs/agentidea.log`（滚动日志，菜单「显示日志…」）、`run/`（「在终端中运行」生成的包装脚本）、`undo/`（编辑器的撤销历史，按文件一份，含改动过的文字；单份超过 2MB 不存，总共最多 500 份 / 50MB，按最近使用淘汰，30 天没用的清掉）、`github_token`（可选）。删掉整个目录就回到首次运行的样子。

## 构建与运行

换一台新机器要装什么（Swift 官方 toolchain、本机签名证书、git 身份、`gh`），
以及每样缺了会怎么报错，见 [`SETUP.md`](SETUP.md)。已经装好的话：

```bash
swift build                 # 编译
swift test                  # 单测（swift-testing）
scripts/build_app.sh        # 产出 .build/AgentIDEA.app 并装到 /Applications
scripts/build_app.sh --no-install
```

首次构建前建议跑一次 `scripts/make_signing_identity.sh`，造一张本机自签证书让应用有稳定身份。

代码、Markdown 与 diff 共用一个 WKWebView；HTML 预览按需创建独立 WebView，与编辑桥隔离。前端依赖（markdown-it、highlight.js、mermaid、CodeMirror 5、web-tree-sitter 与各语言的语法包）已下载进仓库的 `Sources/DesignSystem/Resources/web/vendor/`，构建与运行不需下载依赖；HTML 页面自身引用的远程资源仍按页面要求加载。只有升级前端依赖时才跑 `scripts/fetch_vendor.sh`。

## 发布

```bash
scripts/release.sh 0.3.0            # 跑测试 → 构建 → 打 dmg → 提交推送 → 打 tag → 建 GitHub Release
scripts/release.sh 0.3.0 --local    # 只打到 dist/，不动仓库
```

历史版本都在仓库的 [Releases](https://github.com/aihuangjun/agent-idea/releases)（tag `vX.Y.Z`，dmg 作附件）。
应用里「Agent IDEA → 检查更新…」读的就是最新那个 Release。本地 `scripts/build_app.sh` 装的是 debug 渠道包：
版本号与线上正式包相同时，只有你自己点「检查更新…」才会提示装正式包，后台的自动检查不会把它换掉
（不然刚构建出来要验的那份会在启动后几十秒里被悄悄替换）。仓库现在是公开的，更新不需要凭据；
若改回私有，更新器按 `~/.agentidea/github_token` → `GITHUB_TOKEN`/`GH_TOKEN` → 本机 `gh auth token` 的顺序找。
